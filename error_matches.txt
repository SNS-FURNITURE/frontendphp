## Fix — One SQL command in phpMyAdmin

### Step 1 — Open phpMyAdmin in Plesk

Click the **SQL** tab at the top and paste this **exactly**:

```sql
ALTER TABLE `invoices`
  ADD COLUMN `created_by` INT NULL DEFAULT NULL AFTER `snapshot_json`;
```

Click **Go**.

### Step 3 — Verify


You should now see `created_by` in the list.
